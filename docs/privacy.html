PRIVACY POLICY

Luthifer — luthier helper tools
Effective October 19, 2026 (updated to describe anonymous usage data)

The short version

Everything you enter stays on your device. Luthifer sends a few anonymous usage events so we can see how many people use it, roughly where, and on which devices. There are no accounts, no advertising, and you can turn usage data off on the home screen.

What the app stores

To remember your work between sessions, Luthifer saves the following only on your device, in the app's local storage:

  • the nut width, offsets, number of strings and string gauges you last entered;
  • your chosen units and display settings;
  • string sets you save.

This information never leaves your device. Deleting the app deletes it.

Anonymous usage data

Unless you turn it off, the app and website send these events:

  • app opened;
  • tool opened (which tool, e.g. the Nut Slot Calculator);
  • results viewed, with the number of strings, which preset string set was used (or "custom" / "saved"), and the chosen units.

Each event includes technical details added automatically: device model, operating system, browser, screen size, app version, language, and an approximate location (country and city) derived from your IP address. Events are linked to a random identifier stored on your device, so a returning user is counted once. They are not linked to your name, email or any account, and the measurements you type, the names of your string sets and any other content are never sent.

The data is processed by PostHog, our analytics provider, and used only to understand how Luthifer is used. It is not sold, not used for advertising, and not used to track you across other apps or websites.

Turning it off: switch off "Share anonymous usage data" on the Luthifer home screen. Nothing more is sent from that device or browser.

The website version

The web version of Luthifer works the same way: your inputs and saved string sets are kept in your browser's local storage on your own device and are never sent anywhere. Clearing your browser's data for this site deletes them, along with the random usage-data identifier. The website does not set cookies.

The website is hosted on GitHub Pages. Like any web host, GitHub may process technical information such as your IP address to deliver the pages; see GitHub's privacy statement.

What the app does not do

  • No accounts or sign-in.
  • No advertising, and no tracking across other apps or websites.
  • No personal information collected: the app works fully offline apart from the optional anonymous usage data above.
  • No access to your contacts, photos, location, camera or microphone.
  • No data is sold or shared with anyone.

Children

Luthifer does not knowingly collect personal information from anyone, including children. The anonymous usage data described above is not linked to anyone's identity.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
